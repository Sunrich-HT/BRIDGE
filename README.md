# BRIDGE

**Triangular Fixed-Point Refinement for Long-Horizon Persona Consistency**

ICML 2026 · First author: Haotong Sun

> Code and pretrained adapters will be released here upon publication.

## TL;DR

A triangular Gauss–Seidel fixed-point coupling of three operators (O–L–M) for maintaining persona consistency across long multi-turn dialogues, with a convergence proof and a Lyapunov drift upper bound.

- Backbone: frozen Qwen2.5-32B
- Trainable params: 277M (0.85%)
- PersonaGym: **4.59**
- CoSER: **59.5%**
